# SRS Mini — CampusBook

## Tujuan
CampusBook mengelola reservasi ruang dan peralatan kampus secara terintegrasi.

## Ruang Lingkup
Pencarian ketersediaan, reservasi berulang, persetujuan admin, pencatatan aset,
notifikasi email, dan laporan bulanan.

## Aktor
Mahasiswa, Dosen, Admin Sarana, Teknisi Gudang, Kepala Sarana, dan Layanan Email.

## Asumsi dan Batasan
- Zona waktu Asia/Jakarta.
- Data master ruangan dan alat tersedia.
- Tahap awal menggunakan MySQL dan tidak menyertakan integrasi sistem akademik.
